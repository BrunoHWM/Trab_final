# 🎃 Portal Halloween

## 📌 Sobre o projeto

O Portal Halloween é um projeto desenvolvido para apresentar conteúdos relacionados ao Halloween, utilizando uma estrutura simples de página web.

## 🎯 Objetivo

Criar a estrutura inicial de um site utilizando HTML e praticar os comandos básicos do Git e GitHub.

## 🛠️ Tecnologias utilizadas

- HTML5
- Git
- GitHub
- Visual Studio Code

## 📂 Arquivos do projeto

- `index.html`: página inicial do Portal Halloween.
- `Readme.md`: documentação do projeto.
- `.gitignore`: arquivo responsável por indicar arquivos que não devem ser enviados ao repositório.

## 🏷️ Versão

### v0.1.0 — Versão inicial

Esta versão representa a primeira etapa do projeto, contendo apenas a estrutura inicial, antes da implementação das funcionalidades adicionais.

## 👨‍💻 Considerações finais

Este projeto tem como finalidade praticar a criação de repositórios, organização de arquivos, commits e versionamento utilizando Git e GitHub.
